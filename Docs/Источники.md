# Первичные источники

Проверено при подготовке исходников 17 октября 2026 года. Ссылки служат основаниями для выбора системных API, но не доказательством работы Боггарта на конкретном Mac. Код сторонних приложений не включён; системный исходник Apple просмотрен для уточнения поведения команд, без переноса реализации.

| Источник | Для чего использован |
|---|---|
| [Apple: SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice) | Регистрация и состояние встроенного системного помощника и автозапуска. |
| [Apple: daemon(plistName:)](https://developer.apple.com/documentation/servicemanagement/smappservice/daemon(plistname:)) | Помощник с launchd plist внутри приложения. |
| [Apple: NSXPCConnection.setCodeSigningRequirement](https://developer.apple.com/documentation/foundation/nsxpcconnection/setcodesigningrequirement(_:)) | Требование к подписи удалённой стороны клиента. |
| [Apple: NSXPCListener.setConnectionCodeSigningRequirement](https://developer.apple.com/documentation/foundation/nsxpclistener/setconnectioncodesigningrequirement(_:)) | Требование к подписи входящих клиентов помощника. |
| [Apple QA1340: Idle sleep и forced sleep](https://developer.apple.com/library/archive/qa/qa1340/_index.html) | Почему обычный запрет сна не доказывает поддержку закрытой крышки. Документ архивный: актуальное поведение дополнительно проверяется аппаратно. |
| [Apple: mach_continuous_time](https://developer.apple.com/documentation/kernel/1646199-mach_continuous_time) | Монотонный отсчёт вместо календарных часов. |
| [Apple: thermalState critical](https://developer.apple.com/documentation/foundation/processinfo/thermalstate-swift.enum/critical) | Защитное завершение на основании системного теплового состояния. |
| [Apple HIG: Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers) | Компактное контекстное управление и системное оформление. Реализация использует SwiftUI внутри nonactivating NSPanel для конкретных требований фокуса и наведения. |
| [Apple: SF Symbols](https://developer.apple.com/sf-symbols/) | Системные значки без собственной имитации контролов. |
| [Apple: распространение macOS-приложений](https://developer.apple.com/macos/distribution/) | Различие локальной подписи, готовой поставки и нотариализации. |
| [Apple Open Source: pmset.m](https://raw.githubusercontent.com/apple-oss-distributions/PowerManagement/main/pmset/pmset.m) | Системные команды `disablesleep` и `displaysleepnow`; закрытый набор операций адаптера. |
| [GitHub: actions/checkout](https://github.com/actions/checkout) | Подготовленный сценарий macOS CI; используется фиксированная проверенная версия action. |
| [GitHub: actions/upload-artifact](https://github.com/actions/upload-artifact) | Сохранение журналов проверки CI. Сценарий здесь не запускался. |

Внешняя документация не подтверждает компиляцию этого комплекта. Актуальный статус проверок приведён в `Приёмка.md` и фактических журналах.
