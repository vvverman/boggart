# 0.5.3: доступ к приложению без поиска скрытого значка

Исправлен подтверждённый дефект маршрута запуска: раньше подготовленное приложение
при первом обычном открытии могло не показывать никакого окна. Теперь ручной запуск
сразу показывает управление, повторное открытие возвращает его, завершение
первоначальной настройки ведёт в управление. Опознанный автозапуск остаётся фоновым.

Из NSStatusBarButton удалён NSHostingView. Паук и перечёркнутый месяц рисуются из
той же SwiftUI-геометрии один раз, с тремя масштабами, затем системная кнопка
использует NSImage.isTemplate. Текст, интервалы и контраст рисует AppKit. Это устраняет
зависимость цвета значка от цветовой схемы окна при другом фоне строки меню.

Когда открыто обычное окно, приложение доступно через Dock и Command-Tab. Если
значок остаётся вне доступной области более секунды, вход через Dock сохраняется
до выхода из приложения; лишних всплывающих окон и новых настроек нет. В обычной
панели кнопка «Выйти» вынесена из меню «…». В меню Dock есть остановка сессии.

Новая запись положения собственного statusItem не наследует прежнее недоступное
место. Чужие значки не передвигаются. Полностью переполненную строку меню приложение
не может сделать шире: гарантируемым маршрутом остаётся окно при обычном запуске.
Физическая проверка выреза и крышки на пользовательском Mac по-прежнему нужна.

Добавлены тесты правил ручного/повторного/фонового запуска, Dock при скрытом значке,
тест вызова реального AppDelegate с изолированным состоянием и снимки настоящей
системной кнопки в двух оформлениях. Проверка существования окна не создаёт его сама.
Системное удержание закрытой крышки в UI-тестах не включается.
