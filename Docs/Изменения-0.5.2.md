# 0.5.2: доступ к управлению при скрытом значке

Фиксированные 72–78 пунктов заменены шириной содержимого. Если полная надпись не помещается в доступную область экрана, временно остаётся компактный символ состояния. Для экрана с вырезом используется публичный NSScreen.auxiliaryTopRightArea. При возвращении места подпись восстанавливается с запасом от мерцания. Сохранённая длительность и настройки не меняются.

Повторное открытие через Finder или Spotlight показывает обычное временное окно с тем же ControlPanelView и тем же AppModel. Стандартные закрытие окна и выход из приложения — разные действия: закрытие не останавливает сессию. Постоянного окна и значка Dock нет. Явное открытие панели при недоступной кнопке также использует окно; простое наведение его не вызывает.

Command-перетаскивание не переключает сессию. Чужие значки не переставляются; скрытые API и права универсального доступа не используются.

Добавлены 15 тестов геометрии, а также нативные проверки отдельного окна и доступа при намеренно скрытом statusItem. Проверки интерфейса используют тестовое состояние, не включают удержание закрытой крышки и не доказывают реальную работу на MacBook с вырезом. Даже минимальный значок не гарантированно помещается в переполненной строке меню; независимое окно остаётся резервным путём.
