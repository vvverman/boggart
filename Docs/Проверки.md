# Отчёт о проверках — 0.4.0

17 октября 2026 года. Проверки выполнены локально в Linux x86_64, Swift 6.2.1.

## Подтверждено локально

`Scripts/check.sh`: 122 теста настоящего ядра, 0 ошибок. Проверяется BoggartCore с тестовыми системными адаптерами, не отдельная имитация продуктовой логики. Все 24 Swift-файла проходят разбор грамматики с целью arm64-apple-macosx13.0. Статические проверки комплекта проходят; ровно два пользовательских Toggle, SMAppService/XPC, актуальная версия и разделение истории/восстановления. Сценарии проверены через bash -n, Python-файлы — компилятором Python.

Дополнительно проверен отказ release_gate.py при пустом аппаратном допуске. Отпечаток исходников формируется, но не выдаёт разрешение на выпуск. Логи локальных запусков хранятся вне репозитория; GitHub Actions сохраняет свои логи как артефакт проверки.

## Что покрыто

Конечность начальной сессии, точное продление без общего суточного предела, дубликаты и запоздавшие команды, питание 10 секунд, связь 30 секунд, восстановление, critical, ошибка обязательного журнала, снятие обоих удержаний, необязательная история и повторные записи, числа больше 24 часов, последняя минута, календарные подписи, закрепление панели, последнее нештатное завершение, ограниченная диагностика, проверка номера сборки и запрет старта при обслуживании.

## Не подтверждено этим отчётом

Проверка типов с Apple SDK и действительная компиляция macOS-приложения, подпись и XPC, SMAppService, графический интерфейс и VoiceOver, реальная крышка без монитора, физическое питание, экраны и аппаратное восстановление. Нативное обновление, откат, удаление и нотариальная проверка также не выполнялись в Linux. Состояние удалённой проверки смотрите в GitHub Actions — этот документ не подменяет её результат.

Аппаратно принятых конфигураций: 0. Готовый выпуск и обычный запуск удержания на неподтверждённом Mac заблокированы. Подготовленные сценарии и число тестов не означают готовый подписанный `.app`.
