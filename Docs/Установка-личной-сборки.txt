БОГГАРТ 0.4.1 — ЛИЧНАЯ ПРЕДВАРИТЕЛЬНАЯ СБОРКА

Готовое приложение для macOS 13 и новее. Apple Silicon и Intel.
Xcode, Терминал и самостоятельная компиляция для установки не нужны.

УСТАНОВКА
1. Откройте Boggart-0.4.1.dmg.
2. Перетащите Boggart.app в «Программы». Откройте приложение из «Программ».
3. Если macOS не разрешает открытие из-за неподтверждённого разработчика:
   Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».
   Подтвердите открытие именно Боггарта. Не отключайте общую защиту macOS.
4. В панели Боггарта нажмите «Подготовить Боггарт…».
5. Разрешите помощник в открывшихся системных настройках фоновых объектов.
   Название раздела зависит от версии macOS: «Объекты входа» или
   «Объекты входа и расширения». Подтвердите системный запрос администратора.
6. Вернитесь к Боггарту. После подключения помощника нажмите «Начать пользоваться».

ИСПОЛЬЗОВАНИЕ
Подключите внешнее питание. Нажмите значок в строке меню: начнётся 12-часовая
сессия. Наведение или правый клик открывают панель. Начальная длительность
выбирается от 1 до 24 часов; «Продлить на час» добавляет час без общего суточного
ограничения. Повторный левый клик останавливает удержание.

Перед уходом заблокируйте Mac: Control + Command + Q, затем закройте крышку.
Команда «Погасить экраны» сама по себе не блокирует компьютер.

ВАЖНО ПЕРЕД ПЕРВОЙ НОЧЬЮ
Это предварительная сборка, не заверенный Apple массовый выпуск. Она подписана
отдельным сертификатом сборки, а не Apple Developer ID, и не нотариализована.
Сертификат не устанавливается в доверенные на вашем Mac; приватного ключа
в поставке нет. Приложение и помощник проверяют друг друга по точному сертификату.

Работа с физически закрытой крышкой на вашем Mac ещё не подтверждена.
Сначала проверьте продолжение реальной задачи при закрытой крышке в течение
нескольких минут, затем остановку удержания. Не доверяйте первой непроверенной
сессии важную ночную работу. Ноутбук должен стоять на твёрдой открытой поверхности,
не в сумке. Боггарт не управляет VPN и не гарантирует успех сторонней задачи.

При ошибке не считайте удержание выключенным: откройте панель и используйте
«Повторить восстановление». Диагностика: Настройки → Диагностика → Скопировать.

ОБНОВЛЕНИЕ И УДАЛЕНИЕ
Не заменяйте работающий Boggart.app с активной сессией.
Для этой первой личной поставки при замене иначе подписанной старой сборки
используйте в старом приложении Настройки → Диагностика → Удалить Боггарт,
а затем установите новый пакет. Настройки и локальная история сохраняются.
В версиях 0.1–0.2 сначала используйте их собственный сценарий удаления службы.
Новый сертификат личной сборки может потребовать повторного разрешения помощника.

Для удаления текущей версии: Настройки → Диагностика → Удалить Боггарт.
Приложение сначала снимает удержание, затем отключает свой помощник.
