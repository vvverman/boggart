# Боггарт 0.5.0 — изменения интерфейса

Этот документ заменяет противоречащие ему требования к интерфейсу версий 0.3–0.4.1. Правила конечной сессии, питания, безопасности помощника и восстановления не меняются.

## Принятые решения

- Основная иконка — самостоятельно написанная векторная иллюстрация паука на роликах. Рисуется SwiftUI и используется в .icns, первом запуске и Finder. В строке меню применяется её упрощённый монохромный вариант.
- При активном удержании — перечёркнутый месяц в системном акцентном цвете. Состояние различимо без цвета.
- Ручное размещение NSPanel заменено NSPopover, непосредственно привязанным к кнопке NSStatusItem. Наведение 300 мс, клик и закрепление сохраняются. Никаких ручных координат или зазора в 4 пункта.
- В панели нет Divider, карточек, истории и диагностики. Основные действия сохранены.
- В настройках два переключателя и версия. Во время сессии также виден точный остаток. Нет вложенных разделов и обслуживания помощника.
- Полный таймер — часы:минуты:секунды,сотые; без сброса после суток. Строка меню остаётся спокойной, без секунд. Быстрая перерисовка изолирована внутри видимого представления, не управляет дедлайном и не порождает XPC-запросы.
- Первый запуск открывает самостоятельное нативное окно SwiftUI и начинает первичную регистрацию помощника без поиска кнопки в меню. Системное разрешение подтверждает человек. Нет повторных автоматических запросов по наведению и нет автоматического удержания после настройки.
- Обычный пользовательский DMG оформляется настоящим окном Finder с большой иконкой приложения и настоящей ссылкой на /Applications, светлым Retina-фоном и краткой инструкцией. Это не имитация установщика.

## Границы проверки

Автоматическая приёмка компилирует отдельный вариант UI со сценариями без запуска помощника и операций питания. В личный .app этот код не включается. Светлая/тёмная панели, настройки, первый запуск и привязка системного popover проверяются отдельно от аппаратной работы с крышкой.

Самоподписанная личная поставка не выдаётся за Developer ID или нотариализованный выпуск Apple. При обновлении с иначе подписанной 0.4.1 требуется сначала штатно удалить прежнюю версию.
