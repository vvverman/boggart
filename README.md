# Боггарт

Нативная утилита macOS для временной работы MacBook с закрытой крышкой и погашенными экранами. Только внешнее питание. Панель и настройки — SwiftUI, интеграция со строкой меню — небольшой слой AppKit.

**Текущая версия исходников: 0.4.0. Готовый аппаратно принятый выпуск ещё не подготовлен.** Обычная сборка не включает удержание на неподтверждённых конфигурациях: список проверенных моделей и сборок macOS пока пуст. Успешный ответ `pmset` или модульный тест не доказывает работу под физически закрытой крышкой.

## Пять действий, две настройки

Нажатие на значок включает удержание на сохранённое время; повторное нажатие останавливает. Наведение через 300 мс открывает панель без перехвата фокуса. Правый клик и клавиатурное открытие закрепляют панель до внешнего клика или Esc; взаимодействие с панелью также закрепляет её.

Пять повседневных действий: включить, остановить, выбрать длительность, продлить на час, погасить экраны. Начальная длительность — 1–24 часа, по умолчанию 12. Каждое продление прибавляет ровно час к существующему окончанию **без общего суточного ограничения** и не меняет длительность следующего запуска. Бессрочного режима и автоматического продления нет.

Два переключателя в настройках: показ оставшегося времени и запуск приложения при входе в систему. Автозапуск не включает удержание. История пяти сессий и диагностика свёрнуты; причина последнего нештатного завершения видна в основной панели. Процента батареи, самостоятельного отключения помощника и лишних режимов в обычном интерфейсе нет.

Погашение дисплеев не является блокировкой. Для защиты доступа используйте штатную блокировку macOS. Приложение не проверяет интернет, не переподключает VPN и не знает, завершилась ли сторонняя задача.

## Что изменилось в 0.4

- История отделена от управления сном: ошибка диска не превращает успешную остановку в ошибку удержания. Запись повторяется отдельно; неперсистентные записи могут потеряться при аварии помощника.
- Добавлены короткое объяснение управления при первом запуске, последнее нештатное завершение и копирование диагностики без сбора файлов, задач, серийного номера и сетевых настроек.
- Технические сведения убраны в раскрываемую диагностику. Уведомления о нештатных остановках не назначают собственный звук.
- Обновление из подписанного `.app` и удаление находятся в диагностике. До замены файлов подтверждается снятие удержания; помощник временно запрещает новые сессии. При ошибке операция отменяется, сессия автоматически не возобновляется.
- Добавлен сборочный путь для подписанного и нотариально проверенного `.dmg`. Выпуск запрещён без аппаратных протоколов текущих исходников.

## Проверить исходники

Технический минимум проекта — macOS 13, Swift 5.9 и Apple SDK. Это deployment target, а не перечень подтверждённых конфигураций.

```bash
./Проверить.command
```

На Mac выполняются тесты и компиляция обычного и проверочного вариантов приложения и помощника. Установка, подпись, регистрация службы и изменение сна не выполняются. На Linux проверяются портативное ядро, грамматика macOS-файлов и структура комплекта — без проверки типов с Apple SDK. Логи находятся в `build/` и не входят в репозиторий. GitHub Actions запускает ту же проверку на macOS.

## Собрать для аппаратной приёмки

Для доверенного XPC нужна собственная подпись Apple Development или Developer ID Application. Сертификатов и приватных ключей в репозитории нет; ad-hoc не поддерживается.

```bash
export BOGGART_SIGNING_IDENTITY="Apple Development: имя вашего сертификата"
./Собрать\ для\ проверки.command
# Необязательно: первая установка в /Applications.
./Установить\ для\ проверки.command
```

При единственном подходящем сертификате сборщик может выбрать его самостоятельно. Результат — `build/Boggart.app`. Проверочная сборка явно обозначена в интерфейсе и использует тот же системный адаптер, а не скрытый альтернативный режим. Испытания проводятся под наблюдением по [протоколу приёмки](Docs/Приёмка.md), не сразу ночным запуском.

После установки откройте приложение из «Программ» и явно нажмите «Подготовить Боггарт…». Наведение не запрашивает разрешения. После подготовки удержание не включается автоматически.

## Обновление и удаление

С версии 0.4: **Настройки → Диагностика → Обновить из файла…**. Выберите более новый `.app` с подписью того же разработчика. До остановки проверяются и подготавливаются файлы. После подтверждённой остановки отключаются службы, заменяется приложение, затем восстанавливаются настройки служб — но не сессия. Сохраняется резервная копия для отката. Этот путь ещё требует испытания на Mac.

Для удаления: **Настройки → Диагностика → Удалить Боггарт…**. После подтверждения снимается удержание, отключаются помощник и автозапуск, приложение перемещается в Корзину. Защищённые данные восстановления и локальная история в `/Library/Application Support/Boggart/v3` сохраняются; это не функция полного стирания данных.

При переходе с 0.3 требуется однократная ручная миграция: остановить удержание, дождаться подтверждения, в старых настройках отключить помощник, завершить старое приложение и удалить его, затем установить 0.4. При переходе с 0.1/0.2 используйте их прежний `Удалить.command`, который удаляет старую службу. Не перезаписывайте приложение поверх действующего удержания.

## Подготовить настоящий выпуск

Разработчик сначала проводит аппаратную приёмку, заполняет отдельный JSON-протокол на основе `Docs/Отчёты/Шаблон.json` и добавляет соответствующую модель/сборку macOS в `HardwareValidation.approved`. Протокол связан с отпечатком исходников:

```bash
python3 Scripts/release_gate.py --fingerprint
python3 Scripts/release_gate.py
```

После положительной приёмки, с сертификатом Developer ID и профилем `notarytool` в Связке ключей:

```bash
export BOGGART_SIGNING_IDENTITY="Developer ID Application: имя вашего сертификата"
export BOGGART_NOTARY_PROFILE="имя-профиля-в-связке-ключей"
./Подготовить\ выпуск.command
```

Сценарий проверяет допуск, выполняет сборку, подпись, нотариальную проверку приложения и DMG и прикрепляет результаты проверки. По умолчанию собирается arm64. Он не публикует релиз и не добавляет выдуманные результаты испытаний. Пока аппаратный допуск пуст, готовый выпуск намеренно заблокирован.

## Надёжность и ограничения

Один конечный срок хранит системный помощник; используется монотонный отсчёт. Перевод часов, смена часового пояса и открытие интерфейса не меняют длительность. При потере внешнего питания есть 10 секунд на возврат; при потере связи с приложением — до 30 секунд. Критическое тепловое состояние завершает удержание. После перезапуска помощник сначала восстанавливает изменения и не возобновляет старую сессию.

Снимаются собственный IOPMAssertion и собственное глобальное изменение `pmset disablesleep`. При ошибке сохраняются журнал и состояние восстановления. История не блокирует снятие удержания, но защищённый журнал восстановления остаётся обязательным. Обнаруженный чужой запрет не присваивается и не сбрасывается; одновременное управление глобальным флагом несколькими утилитами не поддерживается.

Работающий ноутбук оставляют на подходящей поверхности с доступом воздуха, не в сумке. Приложение не отключает системную защиту и не гарантирует результат сторонних задач.

## Структура

`Sources/BoggartCore` — ядро сессии и правила представления; `Sources/BoggartPlatform` — адаптеры и проверка подписи; `Sources/BoggartHelper` — системная служба; `Sources/BoggartApp` — SwiftUI и интеграция macOS; `Tests` — тесты; `Scripts` — проверки, сборка и выпуск.
